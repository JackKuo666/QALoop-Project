# QALoop project page

Static project page for QALoop, intended for GitHub Pages. The page is built with HTML and CSS and needs no build step.

## Publish with GitHub Pages

In the repository settings, choose **Pages → Build and deployment → Deploy from a branch**, then select the default branch and the `/ (root)` folder. The expected URL is `https://jackkuo666.github.io/QALoop-Project/` once deployment completes.

## Update the content

- Replace the walkthrough placeholder in `index.html` once the QALoop video is ready.
- Add the paper link and citation when available.
- Verify the demo and code links and the reported figures before publication.
- The web fonts have system-font fallbacks and the site otherwise has no external runtime dependencies.
