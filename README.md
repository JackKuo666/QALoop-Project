# QALoop project page

Static project page for QALoop, intended for GitHub Pages. The page is built with HTML and CSS and needs no build step.

## Publish with GitHub Pages

In the repository settings, choose **Pages → Build and deployment → Deploy from a branch**, then select the default branch and the `/ (root)` folder. The expected URL is `https://jackkuo666.github.io/QALoop-Project/` once deployment completes.
